# speech-cut

**실제로 말한 것에 맞춰 영상을 자릅니다.** 낱말 단위 타임스탬프를 넣으면 컷 결정이 나옵니다 —
음량으로 자르는 도구가 남기는 **재촬영까지 걸러서**.

(영어판: [README.md](README.md))

```console
$ speech-cut transcript.json --source take.mp4 --duration 36.8 -o cutlist.json
cutlist.json
  4 clips, 18.3s kept of 36.8s  (50.3% removed)
  4 removed stretches parked on V2, disabled
```

## 음량으로 자르면 안 되는 까닭

무음 탐지기는 무음은 잘 찾습니다. 말을 틀렸을 때가 문제입니다.

```
  18.2초  "캔들 종가에서 들어갑니다, 점이 자홍색으로 바뀌는—"   ← 끊김
  24.0초  "캔들 종가에서 들어갑니다, 점이 자홍색으로 바뀌는 자리에서."
```

둘 다 소리가 큽니다. 둘 다 남습니다. 결국 손으로 고치게 되고, 그게 바로 줄이려던 일입니다.

어느 쪽을 버릴지 정하려면 **무슨 말을 했는지**를 알아야 합니다. 이 라이브러리가 음량이 아니라
받아쓰기를 받는 이유가 그것뿐입니다.

| | 자르는 기준 | 재촬영 제거 |
|---|---|---|
| auto-editor 등 오픈소스 | 음량·움직임 | ✗ |
| Descript · TimeBolt | 받아쓰기 | ✓ (유료) |
| **speech-cut** | **받아쓰기** | **✓ (MIT 라이브러리)** |

## 재촬영을 가리는 법

세 가지가 생각보다 어렵습니다.

**1. 낱말 시각으로는 테이크가 안 갈립니다.** 받아쓰기는 낱말 끝을 다음 낱말 머리까지 늘여 적어서,
앞 테이크의 마지막 낱말과 뒤 테이크의 첫 낱말이 딱 붙습니다. **6.9초짜리 낱말** 하나를 쟀는데
그 안에서 화자가 멈추고 쉬고 다시 말했습니다. 그래서 **사이에 걸친 침묵**으로도 가릅니다.

**2. 되풀이는 보통 꼬리입니다.** 세 마디쯤 가다 막히면 셋째 마디만 다시 말합니다. 앞 토막에는
멀쩡한 앞부분이 남아 있으니, 통째로 버리지 않고 **꼬리만** 떼어 냅니다.

**3. 이웃한 다른 문장이 재촬영처럼 보입니다.** 이게 제일 위험합니다 — 잘못 지우면 쓰려던 말이
사라집니다.

```
  "청록색으로 바뀐 캔들의 종가에서 매수로 들어갑니다."
  "자홍색으로 바뀐 캔들의 종가에서 매도로 들어갑니다."
```

가르는 열쇠는 **재촬영은 같은 낱말로 시작한다**는 것입니다. 다시 말하는 사람은 그 줄을 처음부터
다시 시작합니다. 대구 문장은 첫 낱말이 다릅니다. 이 한 가지 검사가 대부분을 해결합니다.

### 기본값의 근거 (실측)

프롬프터 낭독 녹화 두 편(12분·16분, 토막 216개). 이웃한 쌍을 전부 재고 사람이 읽었습니다.

| | 닮음 |
|---|---|
| 진짜 재촬영 | 1.00 · 1.00 · 0.98 · 0.98 · 0.96 · 1.00 · 1.00 · 0.91 · 0.84 · 0.83 · 0.81 |
| 대구 문장 — **지우면 안 됨** | 0.72 · 0.63 · 0.62 |

기본 문턱 **0.80** 은 그 사이입니다. 두 녹화에서 **아는 재촬영 7개 중 6개**를 잡고
**대구 문장 3개는 하나도** 안 건드렸습니다. 놓친 하나는 0.84 였지만 첫 낱말이 달랐습니다.

일부러 그쪽으로 기울였습니다 — **오탐은 쓰려던 말을 조용히 지우고, 놓침은 편집자가 지우면
됩니다.** `--retake-similarity` 로 바꿀 수 있습니다.

## 그 밖에 하는 것

| | 왜 |
|---|---|
| 낱말 경계에 컷을 붙인다 | dB 문턱이 아니라서 음절이 안 잘린다 |
| **짧은 숨은 남긴다** | 숨까지 다 빼면 말이 기관총처럼 들린다 |
| 컷을 침묵에서 끝내지 않는다 | 늘어난 낱말 끝 탓에 몇 초씩 정적이 남는다 |
| 짧고 확신 낮은 토막을 버린다 | 0.6초 소리는 대사가 아니라 헛기침이다 |
| 이음매의 되풀이 낱말을 뗀다 | 안 떼면 "그 그" 가 들린다 |
| 1초 미만 조각을 도로 붙인다 | 0.4초 컷은 편집이 아니라 번쩍임이다 |
| 뺀 것을 보고한다 | 사람이 확인할 수 있게 |

라이브러리를 안 쓰더라도 가져갈 만한 한 가지 — 같은 낱말이 앞 컷 끝과 뒤 컷 머리에 있을 때
**글자만 보면 더듬은 것인지 낱말 하나가 컷에 걸친 것인지 알 수 없습니다.** 글자로 떼면 한 번만
말한 낱말이 사라집니다. 낱말의 **정체**를 비교해야 합니다 (`says_it_twice`).

## 안 하는 것

- **렌더하지 않습니다.** 결정만 합니다. 컷 목록을 ffmpeg 나 편집 프로그램에 넘기세요
- **문장 가운데 더듬은 것은 안 뗍니다.** 컷 경계에 걸린 것만 뗍니다
- **대본을 모릅니다.** 재촬영 가리기는 닮음 기반이라 대본이 없어도 됩니다
- **군말 목록이 없습니다.** "음·어" 는 짧고 확신이 낮아 대개 저절로 빠집니다
- **화자 구분·멀티캠 없습니다**

## 어디까지 확인했나

실제 녹화 두 편(12분·16분, 한국어) + `examples/` 의 합성 예제. 시험은 미디어 파일도 인식기도
없이 낱말 목록만으로 돕니다.

안 재 본 것: 긴 영어 영상 · 대화형 다중 화자 · 띄어쓰기 없는 언어
